นำเข้าลูกหนี้รายตัวจาก HIS กับ Statement IPD (CSCD) ระบบจับคู่ด้วย AN แล้วสรุปยอดรับชดเชย ผลต่างสูง/ต่ำกว่าลูกหนี้ และรายที่ยังค้างรับ

ลูกหนี้รายตัว IPD เบิกได้
ไฟล์ .xls / .xlsx / .csv ที่มีคอลัมน์ an, hn, cid, fname, lname, dchdate, debt_amount

STM IPD กรมบัญชีกลาง
เลือกได้หลายไฟล์ STM_xxxxx_IPyyyymm_nn.xls หรือไฟล์ .zip ทั้งโฟลเดอร์

วิธีคิด: ลูกหนี้ 1 AN ตัดครั้งแรกเต็มยอดในงวด STM แรกที่พบ ผลต่าง = พึงรับทั้งหมด − ยอดลูกหนี้ ถ้า AN เดียวกันมีใน STM งวดถัดไป (ปรับปรุง/อุทธรณ์) ยอดในงวดนั้นนับเป็นผลต่างทั้งจำนวน ถ้าไม่พบ AN จะลองจับด้วยเลขบัตรประชาชน + วันจำหน่าย ข้อมูลทั้งหมดประมวลผลในเบราว์เซอร์ ไม่ถูกส่งออกไปที่ใด

คู่มือดึงลูกหนี้รายตัวจาก HOSxP

  1. เปิด HOSxP XE ไปที่ Tools → SQL Query
  2. วาง SQL ด้านล่าง แก้ช่วงวันที่ในบรรทัด i.dchdate BETWEEN ให้ตรงปีงบประมาณที่ต้องการ แล้วกด Run
  3. กด Excel Export บันทึกเป็น .xls แล้วนำไฟล์มาใส่ช่องที่ 1 ด้านบน
PostgreSQL · HOSxP XE 4 · ตัดรายที่มีสิทธิ พรบ. ทั้งฝั่ง visit และฝั่ง IPD
SELECT
    i.dchdate AS dchdate,
    i.hn AS hn,
    i.an AS an,
    CONCAT(p.pname, p.fname) AS fname,
    p.lname AS lname,
    p.cid AS cid,
    COALESCE(a.uc_money, 0) AS debt_amount,
    ip.pttype AS last_pttype,
    COALESCE(a.income, 0) AS income,
    COALESCE(a.paid_money, 0) AS paid_money
FROM ipt i
JOIN ipt_pttype ip ON ip.an = i.an AND ip.pttype_number = 1
JOIN pttype pt ON pt.pttype = ip.pttype
JOIN patient p ON p.hn = i.hn
LEFT JOIN an_stat a ON a.an = i.an
WHERE pt.hipdata_code = 'OFC'
  AND pt.nhso_code = 'O1'
  AND i.dchdate BETWEEN '2025-10-01' AND '2026-09-30'
  -- ตัดรายที่ visit (ฝั่ง OPD/ER) มีสิทธิ พรบ.
  AND NOT EXISTS (
      SELECT 1
      FROM visit_pttype vp
      JOIN pttype x ON x.pttype = vp.pttype
      WHERE vp.vn = i.vn
        AND ( (x.hipdata_code = 'CSH' AND x.nhso_code = '01')
           OR (x.hipdata_code = 'INS' AND x.nhso_code = 'A1') )
  )
  -- ตัดรายที่รายการสิทธิ IPD มีสิทธิ พรบ.
  AND NOT EXISTS (
      SELECT 1
      FROM ipt_pttype ip2
      JOIN pttype x ON x.pttype = ip2.pttype
      WHERE ip2.an = i.an
        AND ( (x.hipdata_code = 'CSH' AND x.nhso_code = '01')
           OR (x.hipdata_code = 'INS' AND x.nhso_code = 'A1') )
  )
ORDER BY i.dchdate, i.an

ข้อควรระวัง: บาง รพ. ใช้คู่ CSH + 01 กับสิทธิชำระเงินเองทั่วไปด้วย ควรตรวจก่อนใช้ว่าคู่โค้ดนี้ตรงกับสิทธิอะไรบ้าง ด้วยคำสั่ง SELECT pttype, name, hipdata_code, nhso_code FROM pttype WHERE (hipdata_code='CSH' AND nhso_code='01') OR (hipdata_code='INS' AND nhso_code='A1'); และ '01' ของ พรบ. เป็นเลขศูนย์ ส่วน 'O1' ของ OFC เป็นตัวอักษร O
